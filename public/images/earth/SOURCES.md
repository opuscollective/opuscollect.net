# Earth imagery

- `blue-marble-*.webp`, `blue-marble-mercator-2048.webp`: NASA Blue Marble (Visible Earth). NASA imagery is in the public domain.
  The source files came from the `three-globe` package examples (MIT licence), resized to WebP. The Mercator copy was
  reprojected from the equirectangular image for the World map's image layer.
- `topology-2048.webp`: elevation map from the same source. It is used as a bump map so the land has relief.
